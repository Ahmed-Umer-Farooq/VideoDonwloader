# 🎬 Video Downloader Pro  

A simple and easy-to-use **Streamlit web application** for downloading videos from **YouTube** and **TikTok**.  

🚀 **[Live Demo → Click Here](https://videodonwloader-5cwgkpyhtz7rw6s5rnugub.streamlit.app/)**  

---

## ✨ Features  

- 🎥 Download videos from **YouTube**  
- 🎵 Download videos from **TikTok**  
- 📱 Clean, modern web interface  
- ⚡ Fast and reliable downloads  
- 📊 Video information preview (title, duration, size, uploader)  
- 🔒 Secure and private (no data stored)  

---

## 🧩 Installation  

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/Ahmed-Umer-Farooq/VideoDonwloader.git
   cd VideoDonwloader
  pip install -r requirements.txt
  streamlit run App.py
  
**💡 USAGE:**
Open the app in your browser (or click the Live Demo link)
Choose between YouTube or TikTok tab
Paste the video URL in the input field
Click “Download Video”
Wait for the video information to load
Click the Download button to save the video

**🛠 Requirements**

Python 3.7+

Streamlit

yt-dlp

fake-useragent
