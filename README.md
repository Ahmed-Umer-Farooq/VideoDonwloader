# Video Downloader Pro

A simple and easy-to-use Streamlit web application for downloading videos from YouTube and TikTok.

## Features

- 🎥 Download videos from YouTube
- 🎵 Download videos from TikTok
- 📱 Clean, modern web interface
- ⚡ Fast and reliable downloads
- 📊 Video information preview (title, duration, size, uploader)
- 🔒 Secure and private (no data stored)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/Ahmed-Umer-Farooq/VideoDonwloader.git
cd VideoDonwloader
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
streamlit run App.py
```

## Usage

1. Open the application in your browser
2. Choose between YouTube or TikTok tab
3. Paste the video URL in the input field
4. Click "Download Video"
5. Wait for the video information to load
6. Click the download button to save the video

## Requirements

- Python 3.7+
- Streamlit
- yt-dlp
- fake-useragent

## Deployment

This app is ready to be deployed on Streamlit Cloud:

1. Fork this repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub account
4. Select this repository
5. Deploy!

## Important Notes
